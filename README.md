# مختبر الجهاز العضلي | الصف الثالث المتوسط

مستكشف تعليمي تفاعلي للفصل الثالث من كتاب الأحياء للصف الثالث المتوسط. الواجهة والشرح بالعربية، ويستخدم نموذجاً تشريحياً حقيقياً ثلاثي الأبعاد بدلاً من رسم توضيحي مبسّط.

## ماذا يتضمن؟

- نموذج ثلاثي الأبعاد قابل للتدوير والتكبير والتحريك، مع زوايا أمامية وخلفية وجانبية.
- اختيار العضلة مباشرة من المجسّم أو من قائمة المناطق، ثم إبرازها وعزلها وإخفاؤها وإظهارها.
- قاعدة تضم 177 بنية عضلية/وترية موزعة على 15 منطقة، مع أسماء عربية وشرح وظيفة موجز.
- دروس تفاعلية غير اختبارية حول أنواع العضلات الثلاثة، وآلية الحركة وثني المرفق وبسطه، ومسار الإيعاز العصبي، وموضوعات صحة العضلات الواردة في الفصل.
- أزرار أمثلة في الدروس تنقلك مباشرة إلى العضلة نفسها في النموذج ثلاثي الأبعاد.

## تشغيل المشروع

المشروع مبني على React وTypeScript وThree.js وReact Three Fiber وVite، ويستخدم Bun 1.4.2 أو أحدث:

```sh
bun install --frozen-lockfile
bun run dev
```

لإنشاء نسخة النشر:

```sh
bun run build
```

سيكون الناتج في مجلد `dist/`. يمكن استضافة الناتج على GitHub Pages أو أي استضافة ملفات ثابتة. يوجد ملف إعداد GitHub Actions في `.github/workflows/deploy-pages.yml` لبناء المشروع ونشره عند تفعيله في إعدادات Pages.

## مصدر المشروع والنموذج

هذه النسخة مبنية على مشروع [OrganUI Muscles](https://github.com/organui/muscles-3d)، مع الاحتفاظ بعارض Three.js، وأدوات التحكم، وخريطة اختيار العضلات، والنموذج ثلاثي الأبعاد الأصلي. أضيفت ترجمة عربية لأسماء ووظائف التراكيب، وواجهة عربية من اليمين إلى اليسار، ودروس مستندة إلى الفصل الثالث من كتاب الأحياء للصف الثالث المتوسط.

بيانات المجسّم مشتقة من **BodyParts3D 3.0**، حقوق النشر لمركز قواعد بيانات علوم الحياة (DBCLS)، ومرخّصة بموجب **CC BY-SA 2.1 Japan**. أجرى OrganUI تعديلات على بيانات المجسّم لتجميع الأجزاء وتبسيط الهندسة وتحويلها إلى GLB. يجب الإبقاء على الإسناد والترخيص وإشعار التعديلات عند إعادة توزيع النموذج أو الصور المشتقة منه. التفاصيل الكاملة في [`public/models/ATTRIBUTION.md`](public/models/ATTRIBUTION.md).

كود التطبيق الأصلي مرخّص MIT؛ راجع ملف [`LICENSE`](LICENSE). ترخيص كود التطبيق لا يغيّر الترخيص المستقل للنموذج التشريحي.

## حدود النموذج

- المجسّم نموذج مرجعي مبسّط لرجل بالغ، وليس تصويراً كاملاً لكل الاختلافات التشريحية.
- بعض العضلات اليمنى واليسرى أو رؤوس العضلة مجمّعة في عنصر اختيار واحد.
- العظام والأربطة ومعظم الأوتار غير معروضة، وقد تغيب بعض العضلات الصغيرة أو العميقة.
- الألوان توضيحية وليست ترميزاً طبياً.
- المشروع أداة تعليمية للاستكشاف، وليس مرجعاً للتشخيص أو القرارات الطبية.

## مطابقة المنهج

المعلومات الدراسية الأساسية في قسم «دروس الفصل» مأخوذة من موضوعات الفصل الثالث: العضلات الهيكلية والملساء والقلبية، تركيب الألياف والحزم، عمل العضلات مع الهيكل العظمي، ثني المرفق وبسطه، الإيعاز العصبي، والإعياء العضلي وضمور العضلات. أُبقيت فقرة سرطان الثدي ضمن عرض موضوع الكتاب مع توضيح مستقل بأنها تتعلق بأنسجة الثدي وليست مرضاً في العضلات الهيكلية.
